# Calisthénie — planning et suivi

Application web (PWA) de planning et de suivi d'entraînement en calisthénie, en français.

- `programme.js` : **tes exercices, séances, planning et règles** — le seul fichier à modifier pour changer l'entraînement.
- `app.js` : le fonctionnement de l'app (commenté).
- `index.html`, `style.css` : la page et son apparence (mode sombre automatique).

Pour l'essayer sur ordinateur : télécharge le dépôt et ouvre `index.html` dans ton navigateur.

⚠️ Ce n'est pas un avis médical. Après une pause, reprends progressivement.
